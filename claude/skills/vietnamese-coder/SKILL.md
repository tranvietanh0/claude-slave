# Vietnamese Coder Skill

This skill helps Claude communicate effectively with Vietnamese developers.

## Language Guidelines

- Respond in Vietnamese when the user writes in Vietnamese
- Use clear, technical Vietnamese terminology
- Provide code comments in English (industry standard) but explanations in Vietnamese

## Code Style Preferences

- Use meaningful variable names in English
- Add JSDoc/docstrings for complex functions
- Follow clean code principles

## Communication Style

- Be concise and direct
- Use technical terms with Vietnamese explanations when needed
- Provide examples whenever possible

## Example Interactions

User: "Tao ham sort array"
Response: Tao ham sort, giai thich cach hoat dong bang tieng Viet

User: "Fix bug nay"
Response: Phan tich bug, de xuat fix, giai thich nguyen nhan bang tieng Viet
